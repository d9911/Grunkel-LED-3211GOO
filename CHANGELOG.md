# Changelog

## 1.0.0 — 2026-10-21

First stable toolkit baseline for the tested Grunkel LED-3211GOO / Expressluck martin / MT5867 / Android 14 build. Stable describes this recorded configuration, not universal firmware support or untested reset/reboot retention.

- English, Spanish and Russian guides with separate initialization commands for Couchy 1.0.6, Projectivy 4.72 and Plume 1.3; official APK links and fixed SHA-256.
- Couchy default HOME with static JPEG, clock/date, six preserved apps and original HDMI/USB cards; Projectivy multilingual Premium/custom-image limitation and Plume English-only/free-theme tradeoff documented.
- Guarded reversible ADB profile; baseline one launcher plus four common apps. Native Netflix, Live TV, Cast, DRM and WebView retained.
- Original Grunkel Photos 0.2.0: USB folder picker, offline image loop every 30s, 5min idle + 25min photos + intended sleep at minute30; no network permission. Full-duration and reboot/reset persistence unverified.
- Original Shortcuts 0.1.0: actual HDMI1–3/AV selection and USB availability/browser/Photos entry; no permissions/services/USB writes. Owner physical remove/reinsert and HDMI1 input session checked.
- Optional laptop HID controls, same-device journals, native Couchy JSON backup/import and private signed-build reserves.
- Compact current AGENTS/evidence, sourced hardware facts, offline make check, explicit public export and only two retained unedited screenshots (current Couchy and historical home-es.png).

APK application versions are independent of toolkit 1.0.0. No firmware image, root/unlock, automatic factory reset or publication is included. See verification.json for exact limits.
